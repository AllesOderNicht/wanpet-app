# 首页与玻璃导航改造（2026-10-30）

## 已实现

- 首页移除信息卡、陪伴与活动说明、共同记忆及绘图入口，保留原场景和宠物直接互动。
- 底部玻璃栏按屏宽 72% 排列，宽度 280–360pt，窄屏保留两侧 16pt，最小高度 56pt，避让安全区；大字体时扩高。
- 首项直接切换小屋/庭院并显示“门外”或“小屋”，后两项为相册和行囊；相册详情保留相册选中态。
- 场景右侧为 48pt、间距 10pt 的设置、聊天、状态圆按钮，使用 SF Symbols，仅显示图标并提供无障碍名称。
- iOS 26 使用原生 UIGlassEffect Clear，旧 iOS 使用系统薄模糊，Android 使用暖色半透明回退；iOS 增强对比度/减少透明度时采用实色背景。
- 聊天、状态、设置及子页使用 Native Stack 全屏导航并隐藏底栏。资料从状态进入；旅行和领取从状态进入；记忆管理与绘图在聊天内部保留。
- Godot 宿主位于导航之外，切页不重建；非场景页面阻止触摸穿透和场景读屏访问。行囊草稿跨底栏切换保留，账号切换清空。

依赖锁定为 @react-navigation/native 7.5.1、native-stack 7.21.0、react-native-screens 4.24.0。后端 API、数据库与登录协议没有修改。旧的物件名称开关已从设置中移除，底栏名称固定显示；旧偏好字段仍兼容读取。
