日期：2026-10-17。用户选定第一张家园候选 `home_window_v1`，首批角色为原创三花猫，风格为清透日系绘本。本文件是本轮四屏的实现依据。世界观、猫咪正式名字、AI 供应商与商业化没有在本轮确定。

本文件记录最初的平面设计、独立位图、设计参数与状态规范。后续已接入家园 2D 走动、场景切换、行囊搭配和宠物资源包导入预览，见 [宠物动画与验收](pet-animation.md)；真实账号、旅行、领取尚未接入客户端。生成图中的文字用于展示层级，实际页面使用独立文本控件，不能把整张截图作为可操作界面。

## 视觉参数

以暖白为底，鼠尾草绿用于操作，天空蓝与暖橘主要留在插画。细纸纹只用于插画，正文下保持干净；不增加满屏米黄滤镜、厚重阴影、堆叠卡片、货币栏或促销标记。

| 语义 | 色值 | 用途 |
|---|---|---|
| paper | #FBFAF5 | 页面底色 |
| surface | #FFFFFF | 底部操作区、清晰文本区域 |
| ink | #3F4A40 | 标题、主要正文 |
| secondary | #687266 | 帮助文案、未选中导航 |
| primary | #4D654F | 主按钮、选中标记、焦点 |
| sageWash | #E7ECDD | 状态底、浅选中区域 |
| outline | #ADB9A3 | 非关键分隔；选中边框改用 primary |
| sky | #DDECF2 | 插画辅助色 |
| apricot | #E8B78B | 插画小面积点缀 |
| error | #9F433C | 错误文字与图形；同时给出文字说明 |

按 sRGB 相对亮度计算：ink/paper 8.87:1，secondary/paper 4.80:1，白字/primary 6.38:1，primary/sageWash 5.30:1。以上是纯色参数对比度，不等于生成图的所有水彩像素均通过可访问性检查。运行时主按钮使用实色底；插画不能垫在正文后降低对比度。

字体使用平台系统字体栈 `-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", sans-serif`，不随资源包嵌入字体文件。中文标题 28/36pt、页面展示标题最多 36/44pt、分区标题 20/28pt、正文与按钮 16/24pt、辅助信息 14/20pt、导航标签 14/20pt。图片里的夸张标题可按这些参数收敛，避免照抄生成字形。

间距使用 4、8、12、16、24、32pt；页面水平留白 24pt。主按钮高 56pt、圆角 28pt；最小按钮/返回/设置热区 44×44pt。物品格圆角 16pt，卡片圆角 12pt，浅描边 1pt，选中描边 2pt 并同时显示勾号。焦点环 2pt primary，向外偏移 3pt。禁用不能只降透明度，保留“数量不足”等明确文字。

## 导航与布局

底部三个入口为“家园 / 旅途 / 收藏”。家园和归来显示当前入口；收藏的“明信片 / 纪念品”是页内切换。行囊作为独立页面或面板，有返回操作，隐藏底部导航，防止准备中误切走。

设计坐标以 390×844 内容画布为参考。截图不含系统状态栏；原生容器必须另加安全区。底部导航高 72pt，操作区和滚动内容在安全区上方排布。状态文案变长、320pt 小屏或字体放大时允许内容滚动，主操作固定在底部，不压缩文字、图标或 44pt 热区。

页面参考热点在 handoff.json 中给出，用于核对意图，不应作为固定设备坐标直接实现。实际使用流式布局和安全区，文字扩展后重新计算高度。

| 页面 | 结构 | 主要操作 |
|---|---|---|
| 家园 | 窗边场景、猫与小包；下方身份、状态、一个主按钮 | 准备行囊；归来待领时改为查看归来 |
| 行囊 | 返回与标题、整理插画、3 个准备位、2×3 库存格、底部保存区 | 点击库存放入/移除，保存行囊 |
| 归来 | 小型归来插画、明信片、单条纪念品明细、领取 | 领取；成功后进入收藏或查看详情 |
| 收藏 | 明信片/纪念品切换、获得数量、两列网格、最近纪念品 | 点已获得资源打开详情 |

收藏详情使用同一张独立图片，标题、数量、获得记录作为文本。已获得项目可查看；未发现项目只显示中性剪影与“未发现”，不得展示真实未获得图案或价格。空册显示“旅途带回的回忆，会收在这里”，并提供“回到家园”。重复获得增加数量或历史记录，不复制多个相同的格子。

## 角色和场景摆放

- 身份：正面画面左橘、右灰，白口鼻/胸/爪、棕眼粉鼻；禁止水平翻转来复用动作。头巾和小包为配饰；不添加正式名字。
- 六张为静态姿势，不是连续动画帧。待机、整理、归来、睡觉的身体花纹细节存在生成差异；动画骨架、侧/背面完整花纹注册和转身仍需另做。
- 独立角色的 visibleBoundsAtAlpha16 与底部中心锚点登记在 manifest。锚点对应整个可见组，不是脚部骨骼关节。整理/归来图包含小包，使用这些图时不要再次叠加包图标。
- 保留完整画布，以 contain 显示；按可见包围盒计算视觉尺寸和落脚点。归来组右侧留白较小，不能对整图做 cover 裁切；头像也不要直接套圆形裁切切掉耳朵。
- 室内、庭院均为 941×1672，不带角色或 UI；单层背景，不声称有可编辑前中后景。室内源图落脚参考为归一化 (0.50, 0.72)，庭院为 (0.50, 0.78)。
- 390pt 家园场景建议宽 390pt、可视高约 536pt。背景保持宽高比、顶部对齐，允许裁去下方空纸；先将源图落脚点变换到显示坐标，再放角色。猫的可见高度约 200–220pt，不以透明画布高度代替身体高度。大字模式优先减少插画占用。
- 明信片源图为 1536×1024，画面下方有浅色留白；详情使用完整 3:2 图。网格可等比缩放或适度居中裁切，但不裁断路径等主体；文字始终放在图外。

## 行为和状态文案

下面是待开发的状态设计，不表示服务端已有这些能力。保存行囊只保存准备；道具在服务端确认出发事务时消耗，UI 不提前扣除。行囊图中的“本次使用”在实现时明确为“出发时使用”，避免误读成保存即消耗。

| 页面/状态 | 显示 | 操作与恢复 |
|---|---|---|
| 家园：在家未准备 | 在家；行囊未准备 | 准备行囊 |
| 家园：准备已保存 | 行囊已备好；等它自在出发 | 调整行囊；不显示立即出发 |
| 家园：旅行中 | 旅行中；有新的风景正在路上 | 查看旅途；使用空家园背景，不把猫留在家 |
| 家园：归来待领 | 已归来；带回了新的回忆 | 查看归来 |
| 行囊：空 | 三个“待选择”位；尚未放入物品 | 保存不可用；不伪造最低道具规则 |
| 行囊：已选 | 选中边框+勾号，显示各物品出发时用量 | 保存行囊；允许移除 |
| 行囊：库存不足 | 数量不足；保留选择供修改 | 对应格不可添加，返回可用物品 |
| 行囊：保存中 | 正在保存… | 禁用重复保存，保留选择 |
| 行囊：明确保存失败 | 未能保存，请重试 | 重试沿用同次请求身份，保留草稿 |
| 行囊：保存结果未知 | 正在确认行囊状态… | 先查询权威状态，不直接显示已备好或再次扣物品 |
| 行囊：库存被其他设备改变 | 物品数量已更新，请重新确认 | 更新库存后标出冲突项，不静默替换选择 |
| 归来：可领取 | 明信片、纪念品、领取 | 服务端确认可以领取后才开放 |
| 归来：领取中 | 正在领取… | 单次提交、禁用重复点 |
| 归来：网络超时/结果未知 | 正在确认领取结果… | 保留卡片；恢复同一操作，先核对权威快照 |
| 归来：明确失败 | 暂未领取成功，请重试 | 可安全重试，不增加客户端库存 |
| 归来：已领取 | 已收进收藏 | 主操作改为查看收藏，不能再次领奖 |
| 收藏：空 | 旅途带回的回忆，会收在这里 | 回到家园 |
| 收藏：已获得/重复 | 名称、图像、×数量；详情展开历史 | 不把重复数量当作新奖励再结算 |
| 收藏：未发现 | 中性剪影；未发现 | 不进入含未获得内容的详情 |
| 通用：加载 | 保持布局的占位与加载文字 | 不无限播放猫咪或伪造加载百分比 |
| 通用：离线/旧快照 | 网络暂不可用，正在显示上次记录 | 允许查看缓存；保存、消耗、领取不可用，提供重试 |
| 通用：会话失效 | 登录已过期，请重新登录 | 安全返回登录；清除其他账号的草稿/缓存 |

行囊返回时保留本账号未提交选择；换账号立即清理。重新取得权威库存后再验证草稿。关闭行囊不是保存成功；不要在离开面板时隐式保存。

## 与当前数据的对应边界

本次核对了 contracts 与 backend-api.md。当前真实能力为注册登录、初始化、快照；初始配置仍是 test_species / 测试宠物 / test_food / test_supply。正式艺术资源不改变这些后端数据，也不能把 test_food 自动解释成便当。

| 展示内容 | 当前可用字段/能力 | 接入要求 |
|---|---|---|
| 身份与宠物显示 | PlayerSnapshot.pet.id/speciesId/nickname/status | 根据正式物种配置映射艺术 ID；图片中的“三花猫”是设计示例，不覆盖真实昵称 |
| 库存数量 | inventory 的 itemId/quantity | 按 itemId 查配置；未知 ID 显示中性占位，不按数组顺序猜图案 |
| 在家 | 当前 pet.status 只有 AT_HOME | 不能从 AT_HOME 推断已保存行囊；该状态字段尚缺 |
| 准备位与准备完成 | 当前没有保存准备接口/字段 | 先确定契约、服务端验证与并发语义，再接保存按钮 |
| 旅程 | activeTrip、TripStatus、serverNow 为公开类型预留 | 当前真实快照 activeTrip 为 null；不能仅凭类型就声称旅程功能已实现 |
| 领取和收藏 | 测试后端已实现 POST /v1/me/trips/:id/claim，快照含 collection | 客户端尚未接入；正式物品配置确认后绑定资源，不能客户端发奖；见 travel-backend.md |
| 回来时间 | 服务端 returnAt 与 serverNow | 设备时间不决定可领奖；本轮未制作倒计时组件 |
| 明信片/纪念品图案 | manifest 中资源 ID | 由正式服务端内容目录映射；设计例图/数量均为合成数据 |

本轮不新增 API 路径或改动 contracts。后续如先做 UI 演示，必须使用隔离的合成数据模式；接真实接口前不能让截图数量覆盖权威存档。

## 加载与交互实现要求

首屏只加载室内、待机和当前导航；行囊/收藏/归来资源按需加载。PNG 为原始资产，运行时优先用 manifest 的 WebP，角色宽 768px、道具/纪念品 256px、导航 128px、场景与四屏预览宽 780px、明信片宽 1024px。四屏预览仅供设计检查，不打入游戏首包。不要将全部源图直接导入首屏，也暂不建立图集或声称真机纹理预算已通过。

导航图标的透明留白不同，28pt 是目标可见图形尺寸，不能直接把整个 128px 导出画布缩成 28pt。根据可见包围盒等比放进 32pt 图形盒，外层热区至少 44pt；完整显示标签。未选中可灰度显示，选中增加下划线与文本状态，不能只靠颜色。加载/选中变化不改变热区位置。

VoiceOver 使用独立可读标签；装饰插画隐藏，物品读“便当，拥有 3，已选 1”。库存不足除颜色外显示文字。所有开关/返回/标签有可访问名称；大字模式按流式布局展开。减少动态效果时保留文字状态反馈。后续动效建议 120–180ms 简单透明度变化；本轮不交付动画、不增加逼迫玩家回来的倒计时或内疚文案。

## 验收范围

已做逐图视觉检查、PNG 解码/哈希/提示词引用检查、实际 alpha 检查、定稿比例检查及 WebP 解码。参数纯色对比度已计算。素材权利/商用相似性审核、整套身体花纹注册、连续动画、运行时文字放大、VoiceOver、点击流程、接口联调、浏览器游戏与 iOS 真机性能均不在已完成验收中。

下一开发切片建议：先完成三准备位与服务端保存准备契约，再用这套素材实现“家园→行囊→已备好”，随后接自主旅行、幂等领取与收藏。不要把保存按钮直接接成 start。
