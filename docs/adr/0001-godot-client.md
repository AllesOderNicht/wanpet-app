# 正式客户端迁移至 Godot 2D

用户于 2026-10-17 确认将整个客户端迁移至 Godot，采用原创水彩分层图片、四方向精灵动画与可交互场景。React/PixiJS 客户端保留作历史对照，不再承担正式交付；现有 NestJS/PostgreSQL 后端继续作为存档与经济权威。Godot 统一承担场景、导航、行为、界面和未来 iOS 导出，接受重写现有 UI 的成本，避免长期维护 Web UI 与游戏引擎之间的桥接。

本轮 Mac 验收，iOS 真机另行进行；只使用 GDScript，版本锁定 4.7.2 与同版导出模板。首版提供三花猫，生活动作仅作陪伴表现；在线 AI、真实养成数值和正式自主出发不在本次迁移范围。
