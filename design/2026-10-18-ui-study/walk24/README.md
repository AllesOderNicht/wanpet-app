# 四方向逐帧行走升级

2026-10-18。原每方向6帧、8fps替换为每方向24帧、18fps，行走速度从48调整为32个场景单位/秒。角色维持原创三花猫水彩身份，不佩戴旧图集的围巾。

素材：assets/godot/pets/walk24/{front,back,left,right}.png。每张1536×1024、RGBA，24个独立绘制姿态，共96帧。全部由内置imagegen生成，提示词在prompts.json；不使用着色器扭曲、不在运行时镜像左右花纹。首轮左向生成了错误猫种，被淘汰；正背向做过留白修正。使用实际透明间隙切分，而非强行按256等格裁切；每帧至少2px强可见轮廓外间距。详细矩形与锚点在正式pet.json，帧检查在frames.json。

前爪/后爪基线和躯干水平中心用于校正图集排布偏移；没有逐帧缩放。clip.scale=2匹配新图集与原生活动作图集不同的像素密度。站立待机使用对应方向的首帧；进食、睡眠和抚摸已在后续生活动作更新中统一为24帧，见 ../life24/README.md。

本轮验证发现并修复一个实际导航问题：NavigationAgent2D使用全局目标和路径点，但旧代码赋入局部目标、减去局部position；当房间偏移时会走偏。现在目标经过room.to_global转换，路径方向和位移采样使用global_position。路径点距离太小时将速度和步态播放倍率归零，避免不移动仍踏步。

验收：80项Godot回归通过。walk24.gd的17项检查通过，包含4方向24帧/无形变材质、两个偏移房间导航同步、接受目标、实际绕行到达、物理步长不超过speed/tick上限。初轮移动测试确实失败，修复坐标后重跑通过，没有移除场景偏移来绕过失败。

图形证据：assets/review/walk24；四方向原地循环预览walk-four-directions.gif与mp4，6秒。预览用放大的角色便于看腿部动作；游戏场景仍按现有空间比例显示。它证明姿态变化，不单独证明真实行走无滑步；实际位置轨迹在apps/godot/.private/walk24/interior.json和courtyard.json。

没有把像素哈希不同、测试通过或帧数增加当成获奖级动画证明。生成纹理仍有轻微帧间差异；iOS实际帧耗时和真机观感尚未验证。现有房间场景美术与首页仍有风格差异，因此完整设计目标尚未宣称完成。
