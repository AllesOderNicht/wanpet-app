# Design System: 丸宠 · 清晨小家（已批准交互稿）

## Overview

**状态：2026-10-22，用户已明确批准按此交互稿一比一开发，RN 与 Godot 接入正在进行；原生验收尚未完成。** 本文保留独立 HTML/CSS/JS 稿的实际设计与演示规则。当前原生实现规则见 [移动端 DESIGN.md](../../apps/mobile/DESIGN.md)，猫与场景比例依据见 [原生比例审计](review/native-proportion-audit.md)。用户批准设计方向与开发，不等于原生实现已达到一比一验收；本文不替换仓库根设计规范。

**Creative North Star: "一个可以直接陪猫的清晨小家"**

已确认的方向是日系手绘、温暖米色、清晨阳光与微风；空间干净有序，同时有充实家具和生活痕迹。完整重设计首页构图、入口、面板和状态，打开即进入可互动的小屋，保留现有三花猫形象。当前交互稿作为原生开发对照，最终完成效果仍需原生验收。

本稿重新编写了界面结构与交互，仅复用既有猫、道具和明信片美术；小屋、庭院、布包为本轮生成素材，来源见 [provenance.json](assets/provenance.json)。实际依据是 [index.html](index.html)、[style.css](style.css)、[app.js](app.js) 与 [浏览器总览](review/overview.png)。[视觉概念图](review/visual-concept.png) 仍是辅助参考；本次批准对象为交互稿，其绘制文字、数量控件、装饰和猫表现不覆盖可点击稿。

**Key Characteristics:**

- 猫与完整生活空间居中；家具承担导航，无常驻底部标签栏。
- 行囊像摊开布包，相册像翻开纸册，操作结束仍留在原场景。
- 墨棕文字、米白纸面和鼠尾草操作色；手绘材质集中在美术与少量不规则轮廓。
- 功能、数量、校验和异常使用真实文本，演示数据有明确边界。

## Colors

主操作和选中状态使用鼠尾草绿；浅选中面配合勾号、描边和 `aria-pressed`，不只靠颜色辨认。墨棕负责主要文字，辅助棕负责说明和数量，米白用于面板阅读；相册纸与明信片纸略有差别，形成同一家居材质中的层次。

木色、植物绿、阳光和天空由插画提供。保留场景细节，正文落在清楚的阅读面上。前置 tokens 提取自实际样式，未将一次性插画颜色扩成通用控件色。

## Typography

标题与主要操作共用楷体栈，正文、数量、输入和说明用系统中文无衬线栈；无下载字体。楷体通过缓和笔形呼应手绘，较长说明保持清楚易读。平台缺失首选字体时会使用后续回退，跨平台字形尚待原生接入时验证。

家园标题随画布宽度变化；面板标题使用 panel-title，窄于（340px）的画布收至（22px）。正文基准（14px），主要说明和次操作多为（12–13px），物件标签（17px），窄屏（15px）。按钮文字通常（17px），窄屏（16px）。字体、名称、状态与数量始终保留为文本，不烘焙到图片中。

## Layout

手机主画布以（390×844）构图：顶部安静的问候与设置，中景家具与物件入口，前景地毯和原猫，底部一条轻提示。庭院延续同一清晨，与房间互相返回。背景完整铺满；猫是独立画布层，点击地毯或方向键移动，点击猫触发抚摸反馈。

| 入口 | 打开内容 | 返回方式 |
| --- | --- | --- |
| 背包 | 布包、两类物品与出发操作 | 收起，保留页面内草稿 |
| 相册 | 明信片、纪念品空位、明信片详情 | 返回相册或合上，回到原场景 |
| 门口 | 庭院/小屋与旅途的明确分流 | 切换场景，或收起旅途 |
| 设置 | 活动、减少动态、物件提示与账号管理 | 收好设置，回到原场景 |

面板单层展开，左右距画布（12px）、底部（24px），最高占可用高度（79%）；门口短菜单最高（48%）。标题、关闭和底部操作不随正文滚走，内容区独立滚动。小于（340px）时内边距降至（16px），布包与配图适当收小，保持可操作面积。

桌面两侧页面选择器、状态切换器、总览和说明均是审稿工具，不属于产品导航。纯画布模式铺满（100vw × 100dvh）。原型的状态栏与底部横条只是展示；正式接入需使用原生安全区和系统行为。

## Elevation & Depth

房间深度来自手绘透视、家具遮挡与斜照阳光。窗帘与植物表现微风的气氛；它们目前是静态画面，没有实现环境风动动画。

面板使用薄纸色面、顶部纸边和柔和投影（`0 8px 24px #35281b38`）；背景遮罩（`#3e34283f`）帮助聚焦并保留所在房间。明信片有轻微旋转和小投影（`0 3px 8px #735d3e18`），相册左侧有细书脊。布包依靠实际插画呈现材质，不把每个库存格都做成厚重容器。

## Shapes

面板、主按钮和物品格采用轻微不对称圆角，具体值见前置 tokens；输入框保持规整，便于读写。物件名称像小纸签，轻微倾斜。明信片保留纸边，场景物件和猫使用自身透明轮廓。圆润不等于所有控件都变成胶囊。

## Components

**家园与原猫。** 猫图集按当前项目资源逐字节复制，未重绘、镜像或新增变形，出处和哈希见 [猫资源清单](assets/cat/manifest.json)。浏览器稿休息仅循环第一张图集的源帧（0–17，24fps，0.75 秒）；左右行走各含（121 帧，24fps）。自动活动约每（22 秒）触发一次，面板打开时停止猫动画。原生接入已在资源定义中使用完整（121 帧、24fps）休息片段和固定姿态族比例；详见移动端文档，完整动画与真机表现仍在验收。

**物件入口与面板。** 物件名称默认可见，可在设置隐藏，点击区仍保留。热点至少（60×52px）；设置与关闭按钮（44×44px），主按钮最小高度（48px），文字操作至少（44px）。面板用 `dialog`、可访问标题和背景 `inert`；关闭按钮、遮罩或 Escape 收起。Tab 约束在面板内，重绘后恢复面板内焦点，关闭后尽可能回到原触发点。焦点环为（2px）操作绿，外偏（4px）。

**布包与库存。** 摊开的布包显示已选物品，下面两列库存展示名称、余量和勾选。每类携带一份；数量用完明确显示“已用完”。收起保留草稿，出发才扣除示例库存；未选择、离线、待确认、忙碌或已有旅途时禁用出发。一次只呈现一个明确主操作。

**旅途与归来。** 在家、旅行中、归来待领和领取完成有独立文案与操作。旅行时家园隐藏猫并留一张状态便笺，面板中的小字号时间不抢过状态。归来先确认领取，再展示已收藏奖励；同一次演示旅途不能重复领取。原型使用手动出发和（60 秒）测试旅程，不代表自主出发规则。

**相册。** 一张大图搭配两列小景，日期、名称、重复数量和总数为真实文本；详情提供返回相册。当前按固定示例顺序展示，不据此承诺按时间排序。无收藏时说明第一张明信片尚在路上并提供整理行囊入口；纪念品只有空态，不虚构奖励。

**账号与表单。** 设置保留“管理账号 → 修改密码 / 退出登录”，也保留登录与注册切换。字段有独立标签，未满足规则时禁用提交；原型用户名不可空，新密码至少（15 字符），该数值是当前演示规则，正式规则以服务端契约为准。改密说明成功后重新登录；退出先说明重新登录及草稿清空，并允许取消。输入不发送、不持久化，成功提示明确为效果预览。

**异常与操作反馈。** 加载提供读取说明、骨架与重试；离线保留已有展示并禁止出发/领取；领取结果未知时禁止重复领取，提供“核对领取结果”。忙碌时按钮显示进行中的动作并禁用，反馈使用可读文字及 `role=status`。所有库存、收藏、账号与倒计时只在页面内存中演示，刷新恢复；真实经济和存档仍由服务端决定。

**减少动态。** 初始化读取系统偏好，并提供页面内设置。启用后停用猫帧推进、自动走动、位移过渡、面板进入、爱心和骨架动画；点击移动即时到位，文字反馈继续有效。普通模式面板用（280ms）短距离进入，猫移动约（1.5 秒）。当前不宣称已处理运行中系统偏好变化或原生辅助功能验收。

## Do's and Don'ts

- **Do** 从这套新空间、新入口和新面板关系实施完整 UI 重设计，保留原猫及现有功能含义。
- **Do** 先保留清楚的操作、数量、关闭、账号动作和异常状态，再适配手绘材质与平台控件。
- **Do** 将本地检查与正式验收分开：[主回归](review/verification.json) 记录 Chromium 在（390×844、320×568、1440×1050）的 36 项检查，错误数组为空；[账号小屏补充](review/account-small-verification.json) 另记录（320×568）下账号、改密、退出的 6 项布局与操作可达检查。用户批准来自明确确认；这些浏览器记录不证明 RN/Godot 接入、真实接口、真机触摸、性能或完整无障碍验收。
- **Don't** 把审稿导航移入手机 UI，恢复常驻底部栏，或把独立界面退回为旧 UI 换色。
- **Don't** 把概念图、静态截图、演示登录、库存变化或领取成功当作生产完成证据。
- **Don't** 把开发授权或已接入源码写成原生验收完成；本文也不自动替换根 `DESIGN.md` 或 `PRODUCT.md`。
