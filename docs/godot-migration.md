# Godot 2D 客户端迁移

状态：Mac 开发验收完成；iOS 真机未验收。依据 2026-10-17 用户逐项确认的《丸宠：Godot 2D 客户端整体迁移》方案。

## 必须完成

- [x] Godot 4.7.2 官方包与同版本导出模板，校验与可复现启动。
- [x] 分层轻俯视小屋、庭院；JSON 唯一布局；遮挡、碰撞、寻路与门口切换。
- [x] 三花猫四方向待机/行走、睡觉、进食、抚摸与可中断的自主日常活动。
- [x] Godot 原生注册登录、家园、真实行囊、测试旅行、归来领取、收藏、设置与改密。
- [x] 内存会话、账号隔离、持久未决请求、同键重试、快照防乱序与服务器时间驱动展示。
- [x] 资源来源/提示词/哈希、校验工具与接口契约测试。
- [x] 独立 PostgreSQL 集成和百次并发验收。
- [x] Mac 导出包操作测试、截图、录屏及连续 15 分钟测试。
- [x] 切换默认入口、同步现有文档；iOS 配置预留但不声称真机验收。

## 固定边界

保留三花猫与水彩风格，重新制作可分层的活动空间。无 Blender/3D 建模，不以整张背景贴图冒充家具分层。使用已有测试道具和 60 秒测试旅程，不改经济规则。家园动作不扣库存。账号每次启动重新登录；用户资源包导入暂不提供。保留原客户端与已有工作区改动，不推送或部署。

## 实施记录

- 2026-10-17：读取现有工作区、客户端、服务端与测试；确认无现成 Godot 工程；本机为 Apple Silicon，Xcode 已可发现。开始下载官方工具与制作分层素材。

## 已执行验证

- 官方 macOS 包与导出模板 SHA512 校验通过，引擎实际版本 4.7.2.stable.official.ed1daf0bf。
- scaffold 14 项文件/配置检查、现有 TypeScript 类型检查、原客户端 12 项和后端 7 项单元测试通过。
- 独立 PostgreSQL 14.18 测试库中 26 项集成检查通过，包括百次并发初始化、出发、领取及事务回滚。
- Godot 62 项检查通过，无引擎错误日志；覆盖原生页面、导航、配置、401/429/断网、旧响应、账号隔离和同键重试。
- 图形与真实后端验收 45 项通过，含客户端重建后恢复同一账号/旅程、真实 60 秒归来、重复领取不增发。15 分钟循环实测 902.057 秒，节点数 27–34，静态内存约 185.3–185.4 MiB，采样帧率 48–52 FPS（本机运行环境数据，不代表 iPhone 性能）。
- 最终默认构建成功；导出包内容检查与本地签名校验通过。实际打开导出的独立 .app，登录本地后端、显示小屋、切换庭院并缩放窗口通过。
- 源图保留，新增 10 张正式 PNG、完整提示词/来源/SHA256、11 个动作片段；有运行截图和 80 帧/8 秒动作录像。
