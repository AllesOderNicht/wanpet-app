# 丸宠 · 清晨小家交互 UI 稿

2026-10-22，**待用户视觉审阅**。这是从新构图、新入口和新面板结构出发的独立设计原型；正式 React Native、Godot、服务端、存档与全局设计规范均未在本轮修改。

## 打开与审阅

- 本机预览：http://127.0.0.1:4176/
- 八屏总览：http://127.0.0.1:4176/?view=gallery
- 纯手机画布：http://127.0.0.1:4176/?embed=1
- 从本目录运行 `python3 -m http.server 4176 --bind 127.0.0.1` 可重新启动预览。

在家园点击猫、地毯、背包、相册和门口。门口区分庭院与旅途；行囊选择物品后出发，60 秒后归来。右侧审稿工具可直接切换旅行、归来、空相册、离线、待确认和加载状态。左侧可检查 8 个主要页面；它是审稿导航，不属于手机 UI。

全部数据均为示例，所有变化只存在页面内存。登录输入不发送、不保存；刷新恢复初始演示。不会连接真实后端。

## 已确认的设计依据

1. 先陪伴，再操作；猫与生活空间是主角。
2. 保留现有三花猫形象与素材，场景与整套 UI 重设计。
3. 合并原观赏首页和小屋活动，打开即可互动。
4. 功能入口融入物件，无常驻底部导航。
5. “简约”指干净有序；家具应更充实。米色清晨、柔和阳光、微风和温馨感。
6. 行囊、旅途、相册在家园上展开，关闭后回到原场景。
7. 用户已批准开始制作交互稿；之后强调明确手绘风，并要求完整 UI 重设计。首张写实场景及基于它的初次修改不作为此稿的界面方案。

## 新结构

| 对象 | 行为 | 返回 |
| --- | --- | --- |
| 猫 | 轻抚反馈 | 保持家园 |
| 地毯/空地 | 点击与方向键移动 | 保持家园 |
| 背包 | 打开布包、选择物品 | 收起保留本次草稿 |
| 相册 | 最近大图、其他风景、详情 | 合上返回原房间 |
| 门口 | 进入庭院或查看旅途 | 关闭回到房间 |
| 设置 | 动效、物件提示与账号 | 收好返回原场景 |

物件提示可关闭，实际点击区保留。功能面板使用单层模态、明确关闭、Escape 及键盘焦点约束；小屏内容滚动，底部主操作固定。

## 文件与素材

- `index.html`、`style.css`、`app.js`：独立可点击原型及审稿外壳。
- `cat.js`、`assets/cat/manifest.json`：当前猫素材、动画图集与原始文件哈希。图集复制逐字节相同，未重绘或镜像。休息只使用首张图集的 18 帧，左右走动各 121 帧；不代表完整原生动画已验收。
- `assets/room.png`、`courtyard.png`、`bundle.png`：内置 image_gen 新制素材；提示词在 `assets/generated-prompts.json`，并写入对应 PNG 元数据。
- `assets/provenance.json`：来源清单；明信片与道具复用已有项目美术。
- `review/visual-concept.png`：完整界面视觉概念，尚未获用户视觉批准；其文字、数量不覆盖交互稿的实际状态规则。
- `review/*.png`：原型真实浏览器截图，包含 8 个主要界面与状态、小屏检查。
- `review/verification.json`：实际执行的交互检查。

## 验证与边界

已在 390×844、320×568、1440×1050 的 Chromium 浏览器检查。36 项检查涵盖抚摸、键盘走动、选择与草稿、旅行离家、示例库存变化、重复出发禁用、领取与收藏、详情、键盘退出、庭院返回、设置、登录/改密/退出、模态焦点恢复、空态、离线、待确认、加载恢复和小屏布局；无 JavaScript 运行错误。图片解码完成后才截取审稿图。

这些验证只适用于本地设计稿。尚未进行 RN/Godot 接入、真实接口联调、真机触摸/性能/无障碍验收。只有用户审稿通过，才开始正式前端重构。

当前原型保留 60 秒测试旅行与手动出发，未把尚未实现的自主出发当作现有能力。纪念品展示空态，未捏造新的实际奖励。

纯色对比度：墨棕/纸白 8.30:1，辅助文字/纸白 5.21:1，主按钮文字/鼠尾草底 5.01:1。此计算不代表场景插画上的所有像素或真机无障碍已通过。

账号面板补充检查：`review/account-small-verification.json` 另有 6 项 320×568 检查，覆盖账号管理、修改密码与退出确认的横向布局和操作可达性。
