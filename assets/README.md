# 仓库资源范围

Git 只保存代码、配置、文档和当前代码/场景/测试使用的美术资源。
`runtime-files.json` 列出保留资源，覆盖 RN、独立 Godot、历史 Web 客户端与测试。
`godot/manifest.json` 保存保留的 Godot 资源及其来源、许可证和校验和。
`manifest.json` 保留历史制作来源，其中原稿路径可能只存在于本地档案。

动画原视频、解码帧、蒙版、候选图集、旧设计稿和 QA 截图不再纳入 Git，
已有本地文件保留。历史文档中的截图和制作过程链接可能只在原工作区有效。
这些素材不能视为已有异地备份；需要重新制作资源时，应先单独归档制作源文件。

新增或替换美术时，同时更新 `runtime-files.json`、`.gitignore` 的资源白名单及
对应来源清单，运行 `npm run check:assets`。未使用的素材放在被忽略的制作目录。
Android/iOS 中直接引用的字体等原生资源仍保留在各自工程目录。

可重新生成的构建目录不纳入 Git。清理缓存后，下一次原生构建会重新编译；
Godot 资源副本通过 `node scripts/sync-godot-assets.mjs` 恢复，移动端资源包通过
`npm run mobile:prepare-game` 恢复。

2026-10-30 按明确授权将当前版本重建为单个初始提交，移除旧制作资源的提交历史。
旧克隆不要直接合并或推送旧分支，以免重新引入旧历史；请重新克隆。
Git 托管平台对失去引用对象的物理回收时间由平台决定。
